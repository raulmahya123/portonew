Seismic AI Data Pipeline

Sistem monitoring dan pipeline data OBS untuk membaca sensor, melihat waveform, melakukan spectral fitting PSD, dan menyiapkan dataset seismik untuk analisis Machine Learning.

info Ringkasan Proyek

Pengembangan pipeline data seismik untuk memonitor data OBS, meninjau sinyal waveform, mengolah spectral fitting PSD, dan menyiapkan data yang lebih bersih untuk proses analisis serta model Machine Learning.

warning Tantangan Bisnis

Data sensor seismik memiliki noise tinggi, variasi format, dan perlu dipantau secara konsisten. Tim membutuhkan cara cepat untuk melihat status sensor, preview waveform, dan kualitas data sebelum masuk proses analisis lanjutan.

lightbulb Solusi Arsitektur

Membangun dashboard monitoring dan pipeline Python untuk ekstraksi data sensor, cleansing, feature extraction, visualisasi waveform, spectral fitting PSD, serta export dataset untuk proses analitik dan Machine Learning.

Fitur & Implementasi Utama

  • check_circleDashboard OBS Phase-1 untuk melihat data sensor, GPS latency, timestamp, dan status monitoring.
  • check_circlePreview waveform per channel agar sinyal bisa dicek langsung dari tabel monitoring.
  • check_circleSpectral fitting PSD untuk membandingkan data, model, dan noise pada domain frekuensi.
  • check_circlePipeline cleansing dan normalisasi data sensor sebelum masuk proses analisis.
  • check_circleFilter data berdasarkan interval waktu, health, station, channel, dan status auto-refresh.
  • check_circleExport data untuk analitik lanjutan dan kebutuhan review engineering.
  • check_circlePersiapan dataset untuk model Machine Learning berbasis sinyal dan fitur seismik.
  • check_circleKolaborasi jarak jauh dengan tim engineering untuk validasi hasil analisis dan iterasi pipeline.
